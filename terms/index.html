What this service is
Watermelon Time is a free, independent hobby project run by a resident of Albuquerque, New Mexico. Using local weather data and web camera, it determines when sunset conditions over the Sandia Mountains are likely to produce the "Watermelon Time" glow, and sends subscribers a single text notification when that happens.
